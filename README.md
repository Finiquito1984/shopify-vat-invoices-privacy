# Privacy policy — EU VAT Invoices for Shopify

Public privacy policy for the Chrome/Edge extension **EU VAT Invoices for Shopify**, in English and Portuguese.

This repository is meant to be served with GitHub Pages (main branch, site root):

- English: https://finiquito1984.github.io/shopify-vat-invoices-privacy/
- Portuguese: https://finiquito1984.github.io/shopify-vat-invoices-privacy/pt/

The contact form uses a free [Web3Forms](https://web3forms.com) access key in `site-config.js`. The destination inbox is set only in the Web3Forms dashboard; do not put an email address in these files.

## Publish (GitHub Pages)

The site files live here in the extension repo at `privacy-site/`. To put them online under @Finiquito1984:

1. Create a public GitHub repository named `shopify-vat-invoices-privacy` under the Finiquito1984 account (the built-in GitHub tools cannot create repositories; create it in the GitHub UI or with `gh repo create Finiquito1984/shopify-vat-invoices-privacy --public`).
2. Copy the contents of this folder (not the folder itself) to the repository root on the `main` branch: `index.html`, `pt/index.html`, `styles.css`, `form.js`, `site-config.js`, `README.md`.
3. In the repository: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder: `/ (root)` → Save.
4. Wait a minute, then confirm https://finiquito1984.github.io/shopify-vat-invoices-privacy/ loads. The Portuguese copy is at `/pt/`.

Do not publish a contact email on the page. The Chrome Web Store dashboard contact email stays off this site.
